## Concept
對於學生、教師以及任何常常來往於校園的使用者來說，這個網站能提供方便、及時的美食資訊，防止踩雷。

## 功能介紹
- 分類篩選
- 店家資訊


## 技術介紹
- UI/UX: figma
- 前端: HTML, CSS, JavaScript
- 後端:Node.js, swagger-ui
- 資料庫: MariaDB (MySQL)
